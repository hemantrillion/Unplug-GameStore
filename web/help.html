A little help getting started.

Play offline

  1. Open Discover and download an approved game while connected.
  2. Wait for the verified download confirmation.
  3. Open My downloads and play. This collection works after disconnecting and reopening the installed PWA.

Request persistent storage to reduce eviction risk. Clearing browser data removes downloads. Updates retain old downloads until you remove them.

Publish a game

  1. Create a developer account and verify its email.
  2. Submit a complete HTML file, title, description and new version.
  3. Preview the candidate. Reviewers play-test it and approve, reject or request changes with feedback.
  4. An administrator activates the exact approved release. Rollback selects an older approved artifact with a newer deployment revision.

Game contract v1

  • Maximum 256 KiB, one complete HTML document with doctype, head, and body.
  • Use classic inline JavaScript and CSS. No external resources, network calls, forms, nested frames, SVG, MathML or inline event-handler attributes.
  • PNG, JPEG, WebP, GIF and supported audio may use base64 data URLs.
  • Announce readiness after initialization with window.parent.postMessage({type:'unplug:ready'}, '*').
  • Use pointer/touch and keyboard controls. Provide restart and explanatory text.
  • Versions follow MAJOR.MINOR.PATCH. Published bytes are immutable. Request changes means submitting a new version.

Contract and syntax validation are not malware scanning or proof of gameplay correctness. The browser sandbox denies storage, network and privileged platform APIs. The platform never executes uploaded scripts on the server.

Local administration

The first administrator credentials are generated in .local-data/first-login.txt. Verification and recovery emails are in .local-data/mail/ when SMTP is absent. Three bundled first-party games start as candidates: preview, review and activate them to populate Discover.

Online play

Three in a row pairs signed-in players. Join from two devices or browser profiles. Moves, turns and wins are validated on the server. Waiting and inactive matches expire after 30 minutes.

Distribution

Install the web app through your browser’s installation control. The Android and desktop download channels are listed on HeKuGo. Their buttons are enabled only when corresponding tested release files are available.
